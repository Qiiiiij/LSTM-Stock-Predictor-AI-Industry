# 🤖 LSTM-Stock-Predictor-AI-Industry

面向 **AI 全产业链** 的舆情分析与价格预测系统：从多源采集上中下游新闻 → 情感词典打分 → 环节情绪特征 → **LSTM 预测 AI 主题 ETF** + **产业链选股榜单**，新闻数据同步沉淀为**标注语料数据集**。

## 产业链划分

| 环节 | 覆盖领域 | 新闻关键词（示例） | 代表股票池 |
| --- | --- | --- | --- |
| 上游·算力硬件 | 半导体/芯片/GPU/光模块/服务器/存储 | 半导体、芯片、GPU、光模块、先进封装、HBM… | 北方华创、中芯国际、中际旭创、新易盛、兆易创新、浪潮信息 |
| 中游·模型平台 | 大模型/云计算/AI 平台 | 大模型、AIGC、多模态、DeepSeek、智能体… | 科大讯飞、三六零、金山办公、拓尔思、云从科技 |
| 下游·行业应用 | 智能驾驶/机器人/AI 医疗/AI 终端 | 智能驾驶、人形机器人、具身智能、AI医疗、AIPC… | 德赛西威、中科创达、海康威视、机器人、卫宁健康 |

> 环节、关键词、股票池、ETF 全部集中在 `industry_config.py` 中配置，可按需扩充。

## 功能特性

- **多源新闻采集**：东方财富 + 新浪财经双源，按环节关键词批量检索，自动去重与时间窗过滤（默认近 30 天）
- **情绪分析（两档设计）**：默认本地金融情感词典（A 股通用词 + AI 产业链专属词，支持程度副词加权与否定反转）；预留 LLM API 接口可升级
- **语料数据集**：原始新闻按环节存档，情绪明细即"标注语料"，可供后续 NLP 训练复用
- **行情采集**：AI 主题 ETF（159819/588200）与股票池日线，自动合成环节等权指数
- **特征工程**：环节情绪 × 交易日对齐生成 LSTM 特征宽表；**传导分析**（环节情绪与 ETF 未来 N 日收益的滞后相关）
- **LSTM 预测**：多特征（价格 + 三环节情绪）输入，预测主 ETF 未来 30 个交易日收盘价
- **选股榜单**：环节内个股按「情绪均分 0.6 + 20 日动量 0.4」z-score 加权排名
- **可视化报告**：环节情绪走势、情绪热力图、环节指数走势、ETF 预测图

## 项目结构

```
LSTM-Stock-Predictor-AI-Industry/
├── industry_config.py     # 产业链配置：环节/关键词/股票池/ETF/路径
├── sentiment_dict.py      # 金融情感词典（通用词 + AI 产业链专属词）
├── news_collect.py        # 多源新闻采集（东财 + 新浪，按环节）
├── news_analyze.py        # 情绪分析（词典实现 + LLM 预留接口）
├── market_collect.py      # ETF 与股票池行情采集 + 环节等权指数
├── feature_builder.py     # 特征对齐 + 传导相关性分析
├── lstm_predict.py        # 多特征 LSTM 预测 ETF 价格
├── stock_picker.py        # 选股打分（情绪 + 动量）
├── report.py              # 可视化报告（走势/热力图/指数）
├── data/
│   ├── news/              # 语料数据集（按环节 + 汇总 + 标注明细 + 个股新闻）
│   ├── market/            # 行情 CSV 与环节等权指数
│   └── features/          # 情绪宽表 / LSTM 特征宽表 / 传导分析 / 预测结果 / 选股榜单
└── output/                # 图表（情绪走势、热力图、指数走势、ETF 预测）
```

## 使用流程

```bash
python news_collect.py      # 1. 采集产业链新闻（双源 × 3 环节）
python news_analyze.py      # 2. 情绪打分，生成标注语料与环节情绪宽表
python market_collect.py    # 3. 采集 ETF 与股票池行情，合成环节指数
python feature_builder.py   # 4. 特征对齐 + 传导分析
python lstm_predict.py      # 5. 训练 LSTM，预测 ETF 未来 30 个交易日
python stock_picker.py      # 6. 生成选股榜单
python report.py            # 7. 生成可视化报告
```

> 全部配置（环节/关键词/股票/ETF/时间窗）在 `industry_config.py` 修改，无需改动各模块代码。

## 说明与假设

- 新闻情绪仅覆盖近 30 天，LSTM 训练集中更早交易日的情绪特征以 0（中性）填充
- 未来日情绪不可知，滚动预测时以最近一期情绪值填充（恒定假设）
- 传导分析样本窗口短（约 20 个交易日），相关性结果仅供参考
- 选股榜单为「舆情 + 动量」量化打分演示，未考虑基本面与风控
